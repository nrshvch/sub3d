# Subpar 3D Engine Examples

This directory contains the showcase demos for the `sub3d` software rendering engine. Each example displays different capabilities of the renderer.

## List of Examples

1. **[Isometric World](./isometric-world/)**: A procedural landscape chunk complete with trees, custom unlit fog, and an automatic day/night daylight cycle.
2. **[Boxes](./boxes/)**: A high-performance simulation spinning thousands of colored and textured cubes in real-time.
3. **[Earth](./earth/)**: A 3D textured sphere with zoom controls and a render scale (DPR) slider.
4. **[Cubes 2013 (Legacy)](./cubes-2013/)**: A legacy demo from 2013 showing the original version of the engine (formerly named *scalia*) bundled with requirejs.

## How to Run

To run the examples locally, start the development server from the project root:

```bash
# From the project root
npm run dev
```

Then open the output address (e.g. `http://localhost:5173/examples/`) in your browser to view the interactive index of all demos.
